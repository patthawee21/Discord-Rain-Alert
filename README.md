# ☔ TMD Rain Alert Bot

Discord Bot สำหรับแจ้งเตือนการเกิดฝน โดยดึงข้อมูลจาก TMD Weather Radar (กรุงเทพฯ - หนองจอก)

## 📋 คุณสมบัติ

- แจ้งเตือนพร้อมภาพเรดาร์ทุก 5 นาทีขณะฝนตก (หยุดแจ้งเมื่อฝนหยุด)
- คำสั่ง `/radar` และ `!radar` แสดงภาพเรดาร์ล่าสุดพร้อมวิเคราะห์สถานการณ์
- วิเคราะห์ฝนด้วยสีตาม dBZ (เขียว=เล็กน้อย เหลือง=ปานกลาง แดง=หนัก ม่วง=หนักมาก) พร้อมทิศฝนหนักและแนวโน้ม เพิ่ม/ลด/คงที่
- ตัดแถบ legend และทะเลสีฟ้าออกเพื่อไม่ให้ผลตรวจจับเบี้ยว
- คำนวณ**ระยะทางฝนที่ใกล้ที่สุดถึงจุดหมาย** (ค่าเริ่มต้น = เขตลาดกระบัง กทม.) พร้อมแนวโน้มเข้าใกล้/ออกห่าง + ETA และเตือนพิเศษสีแดงเมื่อฝนเข้ามาในรัศมีที่กำหนด
- รัน 24 ชม. ด้วย `run_247.bat` (watchdog เริ่มใหม่อัตโนมัติ) + เปิดอัตโนมัติตอนล็อกอิน Windows

## 🗂️ โครงสร้างไฟล์

```
discord-rain-bot/
├── bot.py              # entry point (runt ด้วย python bot.py)
├── handlers/
│   ├── config.py       # ตั้งค่า .env + ค่าคงที่ + logger
│   ├── detector.py     # RainDetector — ตรวจจับฝน/ระยะทางจากรูปเรดาร์
│   ├── situation.py    # build_situation — คำวิเคราะห์สถานการณ์ภาษาไทย
│   ├── embeds.py       # build_radar_embed — embed แนบภาพเรดาร์
│   ├── commands.py     # คำสั่ง prefix (!...) + slash (/radar)
│   └── client.py       # RainAlertBot — คอร์บอท + loop แจ้งเตือน 5 นาที
├── .env                # ค่าตั้งค่าจริง (ไม่ต้อง commit)
├── run.bat             # รันครั้งเดียว
└── run_247.bat         # รัน 24/7 (watchdog restart อัตโนมัติ)
```

แก้ฟีเจอร์ไหนก็ไปที่ handler ของหน้านั้น ๆ เช่น เปลี่ยนข้อความแจ้งเตือน → `handlers/situation.py`, เพิ่มคำสั่ง → `handlers/commands.py`

## ⚙️ การตั้งค่า

### 1. ติดตั้ง dependencies

```bash
cd discord-rain-bot
pip install -r requirements.txt
```

### 2. ตั้งค่า .env

คัดลอก `.env.example` เป็น `.env` และแก้ไขค่าต่างๆ:

```bash
cp .env.example .env
```

**ค่าที่ต้องแก้ไข:**
- `DISCORD_TOKEN` - Bot token (มีอยู่แล้วในตัวอย่าง)
- `RAIN_ALERT_CHANNEL_ID` - Channel ID ที่จะส่งแจ้งเตือน (ต้องเติมเอง)

### 3. หา Channel ID

1. เปิด Discord Developer Mode: Settings → Advanced → Developer Mode (เปิด)
2. ขวาคลิกที่ channel ที่ต้องการ → Copy Channel ID
3. เอา ID ไปใส่ใน `.env` ที่ `RAIN_ALERT_CHANNEL_ID`

## ▶️ การรัน bot

```bash
python bot.py
```

 bot จะเริ่มทำงานและตรวจสอบฝนทุก 5 นาที (หรือตามค่า CHECK_INTERVAL_SECONDS ใน .env)

## 📊 คำสั่ง

| คำสั่ง | คำอธิบาย |
|--------|-----------|
| `/radar` หรือ `!radar` | แสดงภาพเรดาร์ล่าสุดพร้อมวิเคราะห์สถานการณ์ |
| `/forecast` หรือ `!forecast` | ดูพยากรณ์อากาศรายชั่วโมง (TMD NWP) |
| `!status` | ดูสถานะปัจจุบันของ bot |
| `!test_rain` | ทดสอบตรวจจับฝนแบบ immediate |
| `!help` | แสดงคำสั่งที่มี |

หมายเหตุ: คำสั่ง slash `/radar` อาจใช้ได้ภายในไม่กี่นาทีหลังบอท login ครั้งแรก (global sync) — ถ้ายังไม่ขึ้นให้ใช้ `!radar` ก่อน และตรวจสอบว่าบอท invite ด้วย scope `applications.commands`

## 🎯 การเตือนระยะทางฝน

- ตั้งจุดหมายใน `.env`: `TARGET_LAT=13.7330169`, `TARGET_LON=100.776543` (ค่าเริ่มต้น = แขวงลำปลาทิว เขตลาดกระบัง กทม.) และชื่อแสดง `TARGET_NAME=ลาดกระบัง (LKB)`
- ระบบแปลง pixel → กม. โดยสมมติว่าจุดกลางภาพ = สถานีเรดาร์หนองจอก และรัศมีภาพ ~100 km (`RADAR_CENTER_LAT/LON`, `RADAR_HALF_RANGE_KM` ปรับสอบเทียบได้ใน `.env`)
- ระยะทางเป็น **ค่าประมาณ (±10-20%)** เหมาะกับการเตือนล่วงหน้า ไม่ใช่ระยะทางจริงที่แม่นยำ
- เมื่อฝนเข้ามาใน `APPROACH_RADIUS_KM` (ค่าเริ่มต้น 40 กม.) แจ้งเตือนจะขึ้นหัวข้อ "⚠️ ฝนกำลังเข้าใกล้จุดหมาย!" พร้อมความเร็ว (กม./5 นาที) และ ETA ที่คาดว่าฝนจะถึง

## 🔮 พยากรณ์อากาศรายชั่วโมง (TMD NWP API)

- **สมัครรับ token ฟรี** ที่ https://data.tmd.go.th/nwpapi/register → Login → กด "Create New Token" (แสดงครั้งเดียว ต้องคัดลอกเก็บ) แล้วใส่ใน `.env` ที่ `TMD_API_KEY`
- บอทส่งสรุปพยากรณ์อัตโนมัติ **ทุก 1 ชั่วโมง** (`FORECAST_INTERVAL_MINUTES=60`) แสดงล่วงหน้า `FORECAST_HOURS=6` ชม. (สูงสุด 48) ที่จุดหมายที่ตั้งไว้
- ข้อมูล: อุณหภูมิ (`tc`), ความชื้น (`rh`), ปริมาณฝน (`rain` มม./ชม.), สภาพอากาศ (`cond` แปลงเป็นไทย 1-12 ตามเอกสาร TMD)
- สรุปอัตโนมัติ: ช่วงเวลาที่คาดมีฝน + ฝนสูงสุด + ช่วงอุณหภูมิ (สีส้ม/เหลือง/เขียวตามความรุนแรง)
- ใช้ 1 request ต่อชั่วโมง (API จำกัด 60 req/นาที) — เรียกด้วย `duration=N` ครั้งเดียวตาม docs ไม่ต้องยิงทีละชั่วโมง
- ยังไม่มี token ระบบจะข้ามการส่งและเตือนใน log ครั้งเดียว (คำสั่ง `!forecast` จะแจ้งว่าต้องตั้งค่า key)

## 🖥️ รัน 24 ชั่วโมง

- `run_247.bat` — watchdog: รัน bot ตลอดเวลา ถ้า bot หยุดจะเริ่มใหม่ใน 10 วินาที ล็อกที่ `bot_watchdog.log`
- ตั้งให้เปิดอัตโนมัติตอนเปิดเครื่องแล้ว (ไฟล์ `rainbot247.bat` ในโฟลเดอร์ Startup ของผู้ใช้) — ต้องการเลิกใช้ให้ลบไฟล์นั้นทิ้ง
- หมายเหตุ: บอทออนไลน์เฉพาะตอนเครื่องเปิดและล็อกอินอยู่ ถ้าต้องการ 24/7 จริงให้ย้ายไปรันบน VPS/เซิร์ฟเวอร์

## 🔧 การปรับค่าตรวจจับฝน

สามารถปรับค่าใน .env ได้ดังนี้:

- `RAIN_DETECTION_THRESHOLD` - ค่า threshold ของการตรวจจับฝน (ยิ่งต่ำยิ่งไว 0.01-0.05)
- `CHECK_INTERVAL_SECONDS` - ระยะเวลาเช็คฝนเป็นครั้ง (วินาที)
- `RAIN_CONFIRM_COUNT` - ต้องตรวจจับฝนต่อเนื่องกี่ครั้งถึงจะส่งแจ้งเตือน
